# python-loader Docs

This directory is for `python-loader`-specific documentation only.

## Good Fits

- repo-local explanation of the current implementation
- compatibility notes about `go-server/`, `client/`, and `server/`
- runtime notes that only make sense inside `python-loader`

## Not A Good Fit

- global architecture notes
- vector design shared across repos
- paper notes
- shared SQL reference documents

Those belong in the workspace root `docs/`.
